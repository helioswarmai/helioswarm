Helioswarm AI / Solana / agent swarm

A swarm of autonomous
trading agents
for Solana tokens

Each agent has its own personality and its own wallet. All of them read one shared board before they act, so the swarm spreads out, gets out together and never trades against itself.

Run it in paper mode

Paper trading is the default. No real funds move until you switch it on twice.

Overview / install

What it does and how to install it

  • Trades with personality

    Six presets, from degen to sniper, deployed as many times as you like. Every agent trades from its own wallet.

  • Moves as one swarm

    Agents share one board, so they spread out, exit together on a whale sale and never buy from each other.

  • Watches and reports

    Groups can also send price alerts to a webhook and log equity and profit or loss.

  • Stays on paper until you say so

    Real swaps need a live config and SWARM_LIVE=1, and they run under spend and rate caps.

Terminal
# get the code
git clone https://github.com/helioswarmai/helioswarm
cd helioswarm && pnpm install

# choose targets, groups and limits
cp swarm.example.json swarm.json

# a paper run of 50 ticks
pnpm start -- --config swarm.json --ticks 50

You need Node and pnpm. A paper run needs no wallet, no RPC and no model key.
